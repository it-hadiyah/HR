# منصة إدارة وتحليل أرصدة الإجازات وتكلفتها المالية

نظام ويب عربي (RTL) كامل: هيكل تنظيمي متعدد المستويات، إدارة الموظفين، محرك احتساب مركزي للأرصدة والقيمة المالية،
نظام مستهدفات هرمي، لوحة معلومات تفاعلية مع Drill-down، تنبيهات وتوصيات، استيراد/تصدير Excel، تقارير، وصلاحيات وسجل تدقيق.

## التشغيل
المتطلبات: Node.js 20+ و PostgreSQL 14+.

```bash
npm install
export DATABASE_URL=postgres://hr:hr@localhost:5432/hr   # أو docker compose up -d db
export JWT_SECRET=<قيمة-عشوائية-طويلة>
npm run db:seed          # ينشئ المنشأة والمستخدم admin (كلمة المرور من ADMIN_PASSWORD أو ChangeMe#2026)
npm run db:seed:demo     # اختياري: بيانات توضيحية مميّزة (57 موظفاً) + حسابات عرض
npm start                # http://localhost:3000
npm test                 # اختبارات محرك الحساب والمستهدفات
```
في الإنتاج: اضبط `COOKIE_SECURE=1` (خلف HTTPS) وغيّر كلمة مرور admin، واحذف البيانات التوضيحية من «الإدارة والإعدادات ← البيانات».

## البنية
- `server/lib/engine.js` — محرك الحساب (استحقاق، ترحيل، رصيد، قيمة مالية). دوال نقية مُختبرة.
- `server/lib/targets.js` — تحويل المستهدفات إلى أيام وتوزيعها دون تضخيم، والتجميع الهرمي.
- `server/lib/context.js` / `analytics.js` — تحميل البيانات وتطبيق الصلاحيات، والمؤشرات والتنبيهات والمحاكاة.
- `server/routes/*` — واجهة API. `server/db/schema.sql` — قاعدة PostgreSQL.
- `public/` — واجهة بلا خطوات بناء (ES modules) مع Chart.js.
- `docs/DESIGN.md` — التصوّر: الشاشات، هيكل البيانات، معادلات الحساب، التنقل، تصميم اللوحة، خطة المراحل.

## قرارات وافتراضات مهمة
- كل المؤشرات تُحسب من المحرك المركزي فقط، والاستحقاق لا يُخزَّن بل يُحتسب من تاريخ الرصيد الافتتاحي (تقييم تاريخي قابل لإعادة الحساب).
- **الفصل بين التقدير والمحاسبة**: القيمة المالية تقديرية (الأيام × الراتب المعتمد ÷ القاسم)، وتُحفظ لقطات شهرية يمكن للمالية أن تُدخل بجانبها القيمة المحاسبية الرسمية. استخدام الإجازة لا يُصرف نقداً تلقائياً؛ التسوية النقدية حركة مستقلة.
- كل المعادلات قابلة للضبط من الإعدادات (طريقة الاستحقاق، القاسم، أيام/تقويمي، الترحيل، سنة مالية، عطلات)، ولا يُفترض تساوي الاستحقاق: يمكن تحديده لكل موظف.
- **قبل الاعتماد الرسمي**: راجع مع الموارد البشرية والمالية أساس أجر اليوم والأيام المستحقة والترحيل والتسويات وفق لوائح جهتك.
- حدود معروفة: الإجازة العابرة لسنتين تُنسب لسنة بدايتها؛ التقارير PDF عبر «طباعة / حفظ PDF» في المتصفح بتنسيق طباعة رسمي.
