# التصوّر والتصميم (المرحلة الأولى المطلوبة قبل البناء)

## 1) الشاشات
دخول ← لوحة المعلومات (KPI + 10 رسوم + تفصيل Drill-down) ← الهيكل التنظيمي (شجرة تفاعلية) ← الموظفون (قائمة/نموذج/ملف الموظف) ←
حركات الإجازات ← المستهدفات (إدخال وتوزيع) ← التحليل والتنبيهات (توصيات، محاكاة التخفيض، التنبؤ بنهاية السنة) ← التقارير (9 تقارير) ←
الاستيراد والتصدير ← الإدارة (السياسات، العطلات، لقطات شهرية، سجل التدقيق، المستخدمون).

## 2) هيكل قاعدة البيانات
`org_units` (شجرة: منشأة/قطاع/إدارة/قسم) — `employees` (+ `employee_allowances`, `salary_history`, `org_history`) —
`leave_transactions` (دفتر الحركات: إجازة/تسوية/تسوية نقدية × معلّقة/معتمدة/مرفوضة/ملغاة) — `targets` (نطاق وحدة أو موظف × سنة × نوع) —
`settings`, `holidays` — `users` — `snapshots`/`snapshot_rows` — `audit_log`. التفاصيل في `server/db/schema.sql`.
يمكن ربط الموظف بأي مستوى (قسم/إدارة/قطاع) إن لم توجد أقسام.

## 3) معادلات الحساب (كلها في `engine.js`)
- الاستحقاق اليومي = الاستحقاق السنوي × أيام الأهلية في السنة المالية ÷ أيام السنة (يراعي تاريخ التعيين ونهاية الخدمة)، أو منح كامل في أول السنة (`upfront`).
- الرصيد في تاريخ = الرصيد الافتتاحي + الاستحقاق − الإجازات المعتمدة ± التسويات − التسويات النقدية، مع إسقاط ما فوق حد الترحيل أول كل سنة إن ضُبط.
- المتاح الآن = الرصيد حتى تاريخ العرض؛ المتوقع نهاية السنة = الرصيد في آخر يوم من السنة (يشمل الاستحقاق المتبقي والإجازات المجدولة المعتمدة).
- الراتب المعتمد للإجازات = راتب معتمد يدوياً أو (الأساسي + البدلات المشمولة)؛ أجر اليوم = الراتب ÷ القاسم؛ القيمة = max(0, الرصيد) × أجر اليوم.
- المستهدف يُحوَّل إلى رصيد مستهدف بالأيام: أقصى رصيد، تخفيض %، أيام مطلوب استخدامها، سقف مالي (÷ متوسط أجر اليوم)، التزام بخطة الاستخدام.
- نسبة الإنجاز = (رصيد البداية − المتوقع) ÷ (رصيد البداية − المستهدف) محصورة بين 0 و100. «محقق» إن كان المتوقع ≤ المستهدف.
- **منع التضخيم**: مستهدف الوحدة يُوزَّع على الموظفين غير الصريحين بالتناسب مع العدد بعد خصم المستهدفات الصريحة للأبناء؛ وإن زادت مستهدفات الأبناء عن الأب يُسجَّل الفرق ويظهر «تعارض».

## 4) التنقل
شريط جانبي ثابت (يتحول لقائمة منسدلة في الجوال)، شريط مرشحات موحّد (سنة، فترة، قطاع ← إدارة ← قسم، حالة)، فتات خبز للتعمّق، والنقر على أي عمود/وحدة/موظف ينقل للتفصيل.

## 5) تصميم اللوحة
ثلاث مجموعات بطاقات (الموظفون والأرصدة / الالتزام المالي / المستهدفات)، ثم 10 رسوم تفاعلية، ثم جدول تفصيلي قابل للفرز والتعمّق. الوضعان الفاتح والداكن، التواريخ ميلادي/هجري، المبالغ بالريال.

## 6) خطة المراحل
1. المحرك والمخطط والاختبارات ✔ 2. API والصلاحيات والتدقيق ✔ 3. الواجهة والداشبورد ✔ 4. الاستيراد والتقارير ✔ 5. التحسينات المقترحة: إشعارات بريدية، تكامل مع نظام الرواتب/الحضور، تقسيم الإجازة العابرة للسنوات، تصدير PDF من الخادم.
