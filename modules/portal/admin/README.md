# لوحة تحكم البوابة

تعدّل اللوحة بيانات البوابة (الموظفين، الهيكل، الروابط، السياسات، المواقع، الرئيسية، اللجان، موظف الشهر) **في قاعدة PostgreSQL** مباشرة،
وترفع ملفات PDF والصور إلى `modules/portal/policies` و`modules/portal/images`.

- **الدخول:** من الصفحة الموحّدة للمنصة، بحساب دوره `admin` أو `content_admin` (مدير محتوى البوابة). لم يعد هناك Windows Authentication ولا `allowed-users.txt`.
- **النسخ الاحتياطية:** قبل كل حفظ تُحفظ نسخة في الجدول `portal_backups` (آخر 40 لكل ملف)، وتُستعاد من زر «السجل».
- **الأمان:** يُتحقق من الدور في الخادم، وتُقبل ملفات PDF والصور فقط مع فحص محتوى الملف وحدّ الحجم، ولا يُستبدل ملف موجود. كل تعديل يُسجَّل في `audit_log`.
- الاستخدام (موظف الشهر، اللجان، الروابط…) كما كان: التعديلات تبقى في الصفحة حتى الضغط على **حفظ التغييرات**.
