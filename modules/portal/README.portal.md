# بوابة هدية الداخلية

موقع ثابت (HTML / CSS / JavaScript) بدون backend ولا أدوات بناء، ويُنشر على IIS (`web.config`).

## الصفحات
| الصفحة | الوصف |
|---|---|
| `index.html` | الرئيسية: مواقيت الصلاة (Aladhan API) وأهم الروابط |
| `about.html` | عن الجهة |
| `employee_info.html` | الهيكل التنظيمي ودليل الموظفين والتحويلات |
| `links_library.html` | مكتبة الروابط |
| `locations.html` | مواقع الفروع |
| `pdf_library.html` | مكتبة السياسات |

## البيانات (`data/`)
المحتوى كله في ملفات JSON، وتعديلها لا يحتاج لمس الكود:
`employeeInfo.json`، `orgStructure.json`، `linksLibrary.json`، `locations.json`، `PoliciesLibrary.json`.

**الهيكل التنظيمي:** تعرضه صفحة الموظفين كشجرة تفاعلية (الرئيس في الأعلى ثم مربعات الإدارات والأقسام، وبالنقر على أي مربع يظهر رئيسه وموظفوه). يُعرَّف في `data/orgStructure.json` (الأقسام والإدارات وتسلسلها). كل وحدة فيها `heads` (رؤساؤها) و`members` (أعضاؤها) و`children` (وحدات فرعية)، والموظف يُربط بوحدته برقم تحويلته. أي موظف جديد في `employeeInfo.json` لا يُذكر في الهيكل يظهر تلقائيًا تحت قسم "أخرى" حتى لا يضيع.

ملفات السياسات توضع في `policies/` ويُكتب اسمها في حقل `file`.

## المكتبات
Bootstrap 5.3.0 (RTL) و Font Awesome 6.4.0 محلية في `assets/vendor/`، فلا يعتمد الموقع على CDN.
الوحيد الخارجي هو API مواقيت الصلاة.

## الهيكل
- `js/script.js` و `css/style.css`: منطق وتنسيق البوابة.
- `hak-site/`: موقع تعريفي منفصل. `hak-site/legacy-tailwind/` إصدار أقدم منه (Tailwind) يحتوي `news.html`.
- `Hadiyah-id/`: ملفات الهوية البصرية (شعارات، خطوط، نقوش، أيقونات، قوالب، صوتيات)، وتُعرض داخل البوابة في `brand.html` من خلال `data/brand.json`. لإضافة ملف جديد ضعه في المجلد وأضف سطره في `data/brand.json`.

## التشغيل محليًا
```
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`. (لا تفتح الملفات بـ `file://` لأن `fetch` لن يعمل.)

> ملاحظة: `data/employeeInfo.json` يحتوي بيانات موظفين (بريد وتحويلات)، فيجب أن يبقى المستودع خاصًا.

## لوحة التحكم
لوحة لتعديل الموظفين والروابط والسياسات والمواقع بدون قاعدة بيانات (تعدّل ملفات JSON وترفع PDF). تفاصيل التثبيت والأمان في `admin/README.md`، وتُفتح من `/admin/`.

## النشر على IIS
انسخ **المجلد كاملًا** (ملفات `.html` ومجلدات `css/` و`js/` و`data/` و`assets/` و`images/` وملف `web.config`) ولا تنسخ ملفات متفرقة، وإلا ظهرت الصفحات بدون تنسيق لأن ملفات HTML الجديدة تعتمد على CSS وJS الجديدين.
ضُبط الكاش في `web.config` على دقيقة واحدة، فتظهر التحديثات للمستخدمين خلال دقيقة، أو فورًا بـ Ctrl+F5.

## صفحة الموظفين: الإمكانيات
- **عرضان:** «الهيكل التنظيمي» (مجلس الإدارة ← الرئيس التنفيذي ← القطاعات ← الإدارات والأقسام ← الموظفون، بفتح تدريجي وخطوط ربط) و«دليل الموظفين» (شبكة بطاقات 5/4/3/2 أعمدة مع ترتيب بالاسم أو الإدارة أو المسمى).
- **البحث:** شريط كبير باقتراحات (اسم، مسمى، إدارة، قطاع، رقم داخلي). اختيار نتيجة يفتح فرعها في الهيكل ويظلل بطاقتها (أو يمرّر إليها في الدليل). `/` للتركيز و`Esc` للمسح.
- **القطاعات (الأزرار العلوية)** بعدد موظفي كل قطاع، و**الفلاتر** (القطاع، الإدارة، المسمى الوظيفي، والموقع إن وُجد حقل `Location` في `employeeInfo.json`). تغيير فلتر من الهيكل ينقل إلى الدليل.
- **مسار التنقل** (breadcrumb) ديناميكي، و**الروابط المباشرة** مثل `employee_info.html#shared/it` و`#directory`.
- **لوحة الملف الجانبية:** القطاع والإدارة والبريد والرقم الداخلي والمدير المباشر والمرؤوسون (تُستنتج من `orgStructure.json`)، مع نسخ وإرسال بريد وحفظ جهة الاتصال (vCard) و«عرض في الهيكل التنظيمي».
- الأنماط في `css/employees.css` (متغيرات التصميم في أعلاه) والكود في `js/employees.js` (يعتمد على `js/script.js`). النسخ يعمل حتى على `http`.
